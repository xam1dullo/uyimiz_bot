# @uyimiz_bot — Domain Context

> Auto-maintained by grill-with-docs skill. Terms evolve as interviews crystallise.

## Glossary

### Bounded Contexts

| Context | Definition |
|---------|-----------|
| **Family** | A group of users sharing data (budget, tasks, reminders). The RLS boundary. |
| **Family Member** | A Telegram user who belongs to exactly one family. Has role: admin, parent, child, guest. |
| **Invite Code** | 8-char nanoid, 7-day expiry, one-time use. Generated by admin, consumed by joiner. |
| **Onboarding** | FSM wizard: language select → has-family? → enter/create → complete. State machine per user. |

### Budget Context

| Term | Definition |
|------|-----------|
| **Transaction** | A single income or expense record belonging to a family. |
| **Category** | Predefined label for transactions (salary, food, rent...). Per-family custom + defaults. |
| **Balance** | SUM(income) - SUM(expense) for a family across all time. |
| **Budget Record** | Entity name for a transaction stored in `budget_records` table. |

### Tasks Context

| Term | Definition |
|------|-----------|
| **Task** | A chore/assignment within a family. Has status (pending→in_progress→completed), priority, points. |
| **Points** | Gamification score per user per week. Awarded on task completion. |

### Reminders Context

| Term | Definition |
|------|-----------|
| **Reminder** | Scheduled notification (one-time, daily, weekly, monthly, yearly). Delivered via Telegram. |
| **Snooze** | Postpone a delivered reminder by N minutes/hours. |
| **Job ID** | BullMQ job identifier stored in DB for restart recovery. |
